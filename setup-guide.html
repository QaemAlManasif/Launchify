Launchify Setup Guide
XENEON EDGE ready

Install Launchify in two minutes

Two files, three steps. There's no account to make, no keys to paste and nothing to configure — run the installer once, import the widget in iCUE, and start pinning apps.

⏱ About 2 minutes 🔁 One-time install 🔒 No account, no internet

Before you start

Four things, and you almost certainly have all of them.

✓

A CORSAIR dashboard LCD

Built for the XENEON EDGE, and works on any iCUE dashboard screen.

✓

iCUE 5.45 or newer

Older versions can't load widgets built on the current framework.

✓

Windows 10 or later, 64-bit

The helper is a Windows app — it reads the desktop's own windows.

✓

Nothing else

No account, no Stream Deck, no Nitro, no internet connection.

Install

Do these once. Every app you pin afterwards just works.

1
Download the two files

Both are on the releases page. Grab them into your Downloads folder.

⤓
Launchify Helper Setup.exe
The background helper, and its installer.
⤓
launchify.icuewidget
The widget you import into iCUE.
Open the latest release
2
Run the installer

Double-click Launchify Helper Setup.exe. It installs the helper to %LOCALAPPDATA%\Launchify, sets it to start with Windows, adds an entry under Settings → Apps so you can remove it later, and starts it. Click OK on the "You're all set!" dialog and you're done with this step.

Expect a SmartScreen warning The installer isn't code-signed, so Windows shows "Windows protected your PC". Click More info, then Run anyway. If you'd rather check first, the whole helper is open source in this repository and you can build it yourself.
What the helper is for A widget is a web page, and a web page can't start a program or touch a window. The helper does that part: it watches your windows, reports which apps are running, and carries out launch, focus, minimize, close and move. It has no window and no tray icon, and it idles down whenever iCUE isn't running.
Prefer portable? You can skip the installer and run LaunchifyHelper.exe directly. Same program — it just won't start with Windows until you switch that on in the widget's Preferences.
3
Import the widget in iCUE
  1. Open iCUE and select your XENEON EDGE from the device list.
  2. Go to the Widgets (dashboard) section for the screen.
  3. Choose Import widget and pick launchify.icuewidget.
  4. Drag Launchify onto a screen area and size it however you like.
It should connect straight away The dot next to the name in the widget's header turns green when it finds the helper. If it says Waiting for Launchify Helper…, tap the Launch Launchify Helper button on that screen.
4
Pin your first app
  1. Tap + in the header (or Add your first app).
  2. Running now lists everything with a window this second. Installed is your Start Menu. Browse… opens a file picker for anything else.
  3. Tap an app to pin it. The row marks itself ✓ Added and the picker stays open, so keep going.
  4. Tap ‹ when you're done. Your apps are waiting on the grid.

Reading a tile

The dot and the line under the name tell you what the app is doing right now.

Closed  — dim icon. A tap launches it.
Running  — a tap brings it forward.
Minimized  — hollow dot. A tap restores it.
In tray  — running with no window at all.
In front  — ringed. The window you're in.
Close?  — waiting for a second tap to confirm.
Worth knowing Running · 3 means three windows. A ×2 chip means the app is running more than once. On more than one monitor, the small number in the corner is the screen it's on — open the app menu (long-press) to send it to another.

Make it yours

Everything below is in the widget's gear, and in iCUE's own widget settings panel.

✓

Assign every gesture

Preferences → Touch. A tap gets three bindings (closed, running, in front); double tap and long press get one each.

✓

Arrange without the menu

Tap the pencil for ‹ › ✕ straight on every app.

✓

Grid or list, any size

App size runs 60–180%. Names and state lines can go off entirely.

✓

Colour the badges

The dot, the state line, the ×2 chip and the monitor number each have their own colour and switch.

Lost the gear? If you turn the header (or the Preferences button) off, long-press the empty background for about a second to bring the dialog back.

If something doesn't work

In rough order of how often it comes up.

The widget says "Waiting for Launchify Helper…"
The helper isn't running.
  • Tap Launch Launchify Helper on that screen — it starts the installed copy.
  • If nothing happens, run Launchify Helper Setup.exe once. The button relies on the launchify:// handler the installer registers.
  • Check it's alive: Task Manager → Details → LaunchifyHelper.exe.
  • Log file, if you want to look: %LOCALAPPDATA%\Launchify\helper.log.
Windows blocked the installer
"Windows protected your PC" appears for any installer that isn't code-signed — click More info → Run anyway. If your browser refused the download instead, use Keep / Keep anyway in its downloads list. The source is in this repository if you'd rather build it yourself.
An app shows as closed while it's clearly running
Launchify matches a pinned app to a running one by its exe path, falling back to the exe name.
  • Some launchers start a different copy of the exe than the shortcut points at (per-version folders, updaters). Re-pin the app from Running now while it's open — that pins the exe actually in use.
  • Store apps that have never been started don't appear under Installed at all; open the app once and pin it from Running now.
A window won't come to the front
Windows only lets the foreground app hand focus over. Launchify does the standard dance to get around that, but two cases still win:
  • A full-screen exclusive game holds focus — alt-tab out of it first.
  • An app that's busy or not responding can't be brought forward until it answers. Force close in the app menu is the way out.
Moving an app to another monitor does nothing, or it snaps back
  • The app needs a window — a tray app has none to move.
  • Some apps manage their own placement and restore their saved position immediately. There's no way around that from outside the app.
  • Opens on waits about twelve seconds for the app's first window. An app that takes longer than that to draw one won't be placed.
An icon is missing, or the wrong one
Icons are read from the exe and cached in %LOCALAPPDATA%\Launchify\icons. A few apps ship a stub exe with a generic icon. Deleting that folder makes the helper read them all again next time the widget asks.
I want it gone
Settings → Apps → Launchify Helper, or run "Launchify Helper Setup.exe" /uninstall. That removes the helper, its start-with-Windows entry, the launchify:// handler and the icon cache. Remove the widget itself from iCUE separately.

What it does and doesn't do

No network, at all Launchify makes no requests to anything. The helper listens on 127.0.0.1:57131 for the widget on the same PC, and that is the whole of its networking. No account, no telemetry, no cloud. Your pinned apps live in the widget; the icon cache and log stay in %LOCALAPPDATA%\Launchify.
Closing is always polite Close app sends the same request clicking the X does, so an app with unsaved work still gets to ask you about it. Force close is the other one — Task Manager's End task — which is why the widget asks twice first.
